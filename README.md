# 🚀 Spaceship Game — Pygame Project

Welcome to **Spaceship Game**, a classic arcade-style 2D game built using **Python** and the **Pygame** library. In this game, you control a spaceship to dodge and destroy falling asteroids in an endless space adventure.

---

### 🎮 Gameplay Overview

* 👾 Control your spaceship using the keyboard
* 💥 Avoid or shoot asteroids to survive
* 🪐 Endless space scrolling background
* 🔊 Sound effects and smooth animations
* 🧠 Great practice for event handling, collision detection, and real-time game logic in Python

---

### 🛠️ Technologies Used

* Python 🐍
* Pygame 🎮
* Object-Oriented Programming (OOP)
* Basic animation and sound integration

---

### 📦 Installation & Running

1. Clone the repository:

   ```bash
   git clone https://github.com/saharnazyp/Spaceship-Game.git
   cd Spaceship-Game
   ```

2. Install required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:

   ```bash
   python spaceship_game.py
   ```

---

### 🎮 Controls

* `← →`: Move spaceship left/right
* `SPACE`: Fire bullets
* `ESC`: Exit game
